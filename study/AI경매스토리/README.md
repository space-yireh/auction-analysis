# 경매스토리 AI 분석 프로젝트

> 부동산 경매 서류를 업로드하면 Claude가 타임라인·권리분석·리스크를 자동으로 분석합니다.

---

## 프로젝트 구성 파일

| 파일 | 등록 위치 | 역할 |
|------|----------|------|
| `지침.md` | 프로젝트 설정 → **지침** | Claude 행동 방식 정의 (분석가 역할·출력 형식·해석 스타일) |
| `타임라인_템플릿.html` | 프로젝트 설정 → **파일** | 타임라인 아티팩트 생성 시 참조하는 HTML 코드 구조 |
| `경매스토리_분석체크리스트.md` | 프로젝트 설정 → **파일** | 권리분석 6단계 판단 기준 (말소기준권리·대항력·특수리스크 등) |

---

## 처음 설정하는 방법

**① 프로젝트 생성**
[claude.ai](https://claude.ai) → 좌측 사이드바 → **프로젝트** → 새 프로젝트 만들기

**② 지침 등록**
프로젝트 설정 → **지침** 탭 → `지침.md` 내용 전체 붙여넣기

**③ 파일 업로드**
프로젝트 설정 → **파일** 탭 → 아래 2개 업로드
- `타임라인_템플릿.html`
- `경매스토리_분석체크리스트.md`

**④ 완료**
설정 저장 후 새 대화에서 바로 사용 가능

---

## 사용 방법

### 기본 분석
프로젝트 내 새 대화 시작 → 경매 서류를 첨부하면 자동으로 2가지를 수행합니다.

```
서류 업로드
    ↓
① 통합 타임라인 HTML 파일 생성 (등기·문건·송달·이벤트·리스크)
    ↓
② 사건 해석 (투자자 관점 3~5개 포인트, 산문 형식)
    ↓
추가 분석 옵션 제시
```

### 업로드 권장 서류

| 서류 | 역할 | 필수 |
|------|------|------|
| 등기사항전부증명서 (건물) | 말소기준권리·권리 이력 | 필수 |
| 등기사항전부증명서 (토지) | 공동담보·토지 권리 | 필수 |
| 문건·송달 내역 | 절차 타임라인 | 필수 |
| 매각물건명세서 | 임차인 현황·인수 권리 | 권장 |
| 현황조사서 | 실제 점유자 파악 | 권장 |
| 감정평가서 | 물건 가치·입지 정보 | 권장 |

### 추가 분석 옵션
타임라인 출력 후 아래 중 선택해 요청할 수 있습니다.

- **[A]** 임차인 대항력 상세 분석
- **[B]** 배당 시뮬레이션 (3개 시나리오)
- **[C]** 특수 리스크 체크 (법정지상권·유치권·신탁·토지별도등기)
- **[E]** NPL / 채권자 관점 분석
- **[F]** 말소기준권리 + 권리분석 풀 리포트

## 파일 업데이트 방법

체크리스트나 지침이 업데이트되면 해당 파일만 교체합니다.
팀원은 별도 설정 없이 즉시 최신 버전으로 분석됩니다.

```
프로젝트 설정 → 파일 탭 → 기존 파일 삭제 → 새 버전 업로드
```
