# 경매스토리 분석 체크리스트

> Claude 프로젝트 파일로 등록하여 사용합니다.
> 분석 시 이 문서를 참조하여 6단계를 순서대로 수행하세요.
> 항목은 실사례 기반으로 계속 업데이트됩니다.

---

## STEP 1. 물건 기본정보 확인

서류에서 아래 항목을 추출합니다.

- 사건번호 및 법원·담당 계
- 채무자 / 소유자 (동일인 여부 명시)
- 소재지 (지번 + 도로명)
- 물건 유형: 단독건물 / 집합건물 / 토지 / 지분
- 용도 (공부상 용도 vs 실제 용도 불일치 시 표기)
- 구조 및 면적 (전유·공용 구분)
- 감정평가액 / 현 최저매각가격 / 유찰 횟수
- 다음 매각기일
- 청구금액 (경매신청채권자 기준)
- 배당요구종기

---

## STEP 2. 말소기준권리 특정

> ⚠️ 이 판단이 틀리면 이후 모든 분석이 무효입니다.

### 2-1. 권리 시간표 작성
건물·토지 등기부의 모든 권리를 접수일 기준 시간순으로 나열합니다.
공동담보는 채권 1개로 처리 (이중 계산 금지).

### 2-2. 말소기준권리 식별
다음 중 가장 먼저 등기된 것이 말소기준권리입니다.

- (근)저당권
- 압류 / 가압류 (근저당 없을 때만 최선순위 가압류가 기준권리)
- 담보가등기
- 경매개시결정

**주의사항:**
- 채권최고액 ≠ 실채권액. 반드시 `채권최고액 X원 / 청구액 Y원` 형식으로 병기
- NPL 양도 이력 확인: 원채권자 → 현 채권자 경로 추적
- 건물·토지에 동일 근저당 → 공동저당 채권은 1개

### 2-3. 소멸·인수 분류

| 구분 | 기준 | 낙찰 후 |
|------|------|---------|
| 말소기준권리 이전 등기 | 접수일 < 기준권리 접수일 | 낙찰자 인수 |
| 말소기준권리 이후 등기 | 접수일 > 기준권리 접수일 | 낙찰로 소멸 |
| 말소기준권리 자체 | — | 낙찰로 소멸 |

---

## STEP 3. 임차인 현황 및 대항력 판단

### 3-1. 기본 정보 추출 (임차인별)
- 성명 / 점유 부분 (주거·상가·혼재)
- 전입신고일 (주택) 또는 사업자등록일 (상가)
- 확정일자 및 일자
- 보증금액
- 배당요구 여부 및 일자

### 3-2. 대항력 판단
```
전입일 < 말소기준권리 접수일 → 대항력 O (낙찰자 인수 위험)
전입일 ≥ 말소기준권리 접수일 → 대항력 X (낙찰로 소멸)
```

### 3-3. 우선변제권 판단
```
대항력 O + 확정일자 O → 배당 순위 획득
배당요구를 했는지 반드시 확인 (안 한 경우 배당 불가, 대항력만 존재)
```

### 3-4. 소액임차인 최우선변제 (2023년 기준, 근저당 설정일 당시 기준 적용)

| 지역 | 보증금 상한 | 최우선변제액 |
|------|------------|------------|
| 서울 | 1억 6,500만원 이하 | 5,500만원 |
| 과밀억제권역 (경기 등) | 1억 4,500만원 이하 | 4,800만원 |
| 광역시 | 8,500만원 이하 | 2,800만원 |
| 그 외 | 7,500만원 이하 | 2,500만원 |

> ⚠️ 기준일에 따라 금액이 다름. 근저당 설정일 당시 기준 적용.

### 3-5. 위장임차인 의심 징후 (2개 이상 해당 시 "위장임차인 의심" 판정)

```
□ 소유자·채무자와 동일 성씨 또는 친족 추정
□ 전입일이 말소기준권리 설정 3~12개월 이내
□ 보증금 미기재 또는 불명
□ 확정일자 없음
□ 배당요구를 하지 않음
□ 현장조사 시 폐문부재 / 점유 실태 불명
□ 실제 거주 흔적 없음 (감정평가서 기재)
□ 임차인통지서 수령 후에도 배당요구 없음
□ 채권자가 위장임차인 배당배제 신청 제출
```

## STEP 4. 특수 리스크 체크

> 해당 없으면 "해당없음"으로 명시합니다.

### [법정지상권]

성립 요건 3가지 모두 해당 시 성립 가능성 높음:
```
1. 토지와 건물이 원래 동일인 소유였는가?
2. 근저당 설정 당시 토지·건물 소유자가 동일했는가?
3. 경매로 토지·건물 소유자가 달라지는가?
```

추가 확인:
```
□ 토지 공유인 경우: 공유자 중 한 명의 건물인가?
□ 미등기 건물(제시외 건물)이 토지 위에 있는가?
□ 감정평가서의 건물 소유 현황표 확인
```
판정: **성립 가능 / 성립 불가 / 불분명** 중 선택

---

### [유치권]
```
□ 현황조사서에 유치권 신고 여부
□ 공사 관련 채권자가 점유 중인지
□ 물건명세서 비고란에 유치권 언급 여부
```

---

### [공유지분 경매]
```
□ 경매 대상이 전체인가, 지분인가
□ 비경매 공유자 인적사항 및 지분 비율
□ 공유자 우선매수청구권 행사 가능성
□ 낙찰 후 공유물분할 소송 필요성
□ 구분소유적 공유 여부 (토지 위 건물을 각각 소유하는 경우)
```

---

### [체납 공과금]
```
□ 등기부 압류 기관 목록 (국세청·지자체·공단 등)
□ 법정기일이 근저당보다 앞선 조세채권 존재 가능성
  → 해당 시 근저당보다 선순위 배당 → 낙찰가에서 먼저 공제
□ 사건내역의 교부청구서 제출 기관 및 금액 확인
□ 용인시 세무2과 등 지자체 세무과 직접 확인 필요 여부
```

---

### [공부 불일치]
```
□ 등기부 vs 건축물대장 용도 차이
□ 공부상 구조 vs 현황 구조 차이
□ 소재불명 건물 부속 (변소·창고 등)
□ 위반건축물 여부
```

---

### [신탁 이력]
```
□ 등기부에 신탁/신탁해지 이력 존재 여부
□ 신탁원부 열람 권고 (법원 경매기록 또는 등기소)
□ 우선수익자 존재 여부 → 낙찰자 인수 가능성
□ 신탁 해지 후 원소유자 귀속 vs 제3자 매매 이력
□ 신탁기간 중 설정된 권리의 효력 판단
```
판정: **신탁 잔여권리 없음 확인 / 신탁원부 확인 필요** 중 선택

---

### [집합건물 특수사항]
아파트·오피스텔·상가 등 집합건물 구분소유권인 경우:
```
□ 관리비 체납 여부 및 승계 범위
  → 낙찰자는 공용부분 체납만 승계 (전유부분 체납은 미승계)
□ 집합건물 규약 확인 (전용사용권·주차권·옥상 등)
□ 대지권 비율 및 대지권 등기 여부
□ 전유면적 vs 공용면적 비율 (수익성 판단 기준)
□ 층별·호별 위치에 따른 효용 차이 (1층 상가·지하 등)
□ 별도등기 존재 여부 (표제부 "별도등기 있음" 표시 확인)
```

---

### [반복 유찰 원인 분석]
3회 이상 유찰 시 가격 외 구조적 원인을 반드시 확인합니다.
```
□ 군용비행장 소음구역 (제1~3종) — 소음 피해 및 증개축 제한
□ 비행안전구역 — 건물 높이 제한
□ 관광특구 / 문화재보호구역 — 용도 및 건축 제한
□ 철도보호지구 — 인접 소음 및 진동
□ 초소형 면적 (10평 미만) — 활용 용도 극히 제한
□ 업무시설·공장 등 비주거 용도 — 실수요 부족
□ 채무자 법인 소멸·폐업 — 명도 협의 불가
□ 관리비 체납 규모 불명
□ 위장임차인 리스크 미해소
```
> 유찰 원인이 구조적이면 낙찰 후에도 동일 문제가 지속됩니다.

## STEP 5. 배당 시뮬레이션

### 시나리오 기준

**일반 물건 (0~2회 유찰):**
- A: 현 최저매각가격
- B: 감정가의 70%
- C: 감정가의 90%

**반복 유찰 물건 (3회 이상 유찰):**
- A: 현 최저매각가격
- B: 현 최저가 + 20%
- C: 청구채권액 (채권자 손익분기점)

### 배당 순서 (법정 순서)

```
1순위: 경매 집행비용
2순위: 법정기일 선순위 조세채권 (국세·지방세)
3순위: 소액임차인 최우선변제
4순위: 당해세 (해당 부동산에 부과된 세금)
5순위: 우선변제권 있는 임차인 (확정일자 기준)
6순위: (근)저당권자·압류권자 (등기 순서)
7순위: 일반 채권자 (가압류 등)
```

### 출력 형식

| 순위 | 권리자 | 청구금액 | A시나리오 | B시나리오 | C시나리오 |
|------|--------|---------|---------|---------|---------|
| 1 | 집행비용 | 추정 | | | |
| ... | | | | | |
| 최하 | 낙찰자 인수 | — | | | |

## STEP 6. 종합 판단

### 리스크 등급

🟢 **안전** — 아래 조건 모두 충족
- 말소기준권리 명확
- 인수되는 권리 없음
- 임차인 대항력 없음 또는 보증금 소액
- 법정지상권 성립 불가
- 체납 공과금 선순위 없음
- 신탁 잔여권리 없음

🟡 **주의** — 다음 중 하나 해당
- 임차인 보증금 확인 필요
- 법정지상권 불분명
- 공유지분 리스크 있음
- 체납 공과금 규모 불명
- 집합건물 관리비 체납 미확인
- 반복 유찰 (구조적 원인 있음)
- 신탁 이력 원부 미확인

🔴 **위험** — 다음 중 하나 해당
- 대항력 있는 임차인의 보증금 인수 확실
- 법정지상권 성립 가능성 높음
- 유치권 신고 존재
- 선순위 조세채권 규모 큼
- 신탁 우선수익자 잔존

---

### NPL 채권자 관점 분석
채권자가 대부업체·유동화회사인 경우 추가 분석:
```
□ 원채권자 → 현 채권자 양도 경로 확인
□ 채권자 추정 매입가 (청구액의 60~80% 범위)
□ 채권자 손익분기점 낙찰가 역산
□ 채권자 직접입찰 가능성 (채권 상계 시 실납입 최소화)
□ 기일연기·변경 신청 이력 → 전략적 의도 해석
```

### 입찰 전 필수 확인사항
현장·법원·행정 확인이 필요한 항목을 최대 5개 명시합니다.

### 투자자 최종 의견
적정 입찰가 범위와 한 줄 투자 판단.

## 흔한 오류 방지

| 오류 유형 | 잘못된 판단 | 올바른 판단 |
|---------|-----------|-----------|
| 공동담보 이중 계산 | 건물+토지 근저당 각 3.6억 = 7.2억 | 공동저당 채권 1개 = 3.6억 |
| 가압류를 말소기준권리로 오인 | 2023 가압류가 기준권리 | 2021 근저당이 진짜 기준권리 |
| 채권최고액을 실채권으로 혼동 | 3.6억 전액 배당 | 청구액(원금+이자)이 실채권 |
| 대항력 판단 기준일 착오 | 전입일 vs 근저당 설정일 | 전입일 vs 근저당 접수일 |
| 소액임차인 기준 지역 착오 | 전국 동일 기준 | 수도권/광역시/기타 구분 |
| 집합건물 관리비 전액 승계 | 체납 전액 낙찰자 부담 | 공용부분만 승계, 전유부분 미승계 |
| 신탁 이력 무시 | 신탁해지 = 리스크 없음 | 신탁원부 확인 전까지 우선수익자 잔존 가능 |
| 반복유찰을 가격 문제로만 해석 | 더 내려가면 팔린다 | 구조적 원인 파악 선행 필요 |
