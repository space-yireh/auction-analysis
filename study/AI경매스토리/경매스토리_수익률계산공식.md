# 경매스토리 수익률 계산 공식

> "수익률 계산해줘" 요청 시 아래 공식을 적용합니다.
> 사용자가 제시한 값을 우선 사용하고, 없으면 공식 기본값을 적용합니다.

---

## 상가 수익률 계산

### 자금 구조

| 항목 | 계산식 |
|------|--------|
| 낙찰가 | 사용자 제시값 |
| 보증금 | 낙찰가 × 10% |
| 대출 | 낙찰가 × 80% |
| 취득세 | 낙찰가 × 5% |
| 투자비 | 낙찰가 - 대출 + 취득세 |

### 임대 수익

| 항목 | 계산식 |
|------|--------|
| 임차 보증금·월세 | 사용자 제시값 사용 |
| 대출이자 (월) | 대출 × 연 5.6% ÷ 12 |
| 월수입 | 월세 - 대출 월이자 |
| 년수입 | 월수입 × 10개월 (세금·예비비 보수적 반영) |
| 실투자금 | 투자비 - 임차보증금 |
| **수익률** | **년수입 ÷ 실투자금** |

### 출력 형식

결과는 표 형태로 **자금구조(좌) · 임대수익(우)** 분리 제시합니다.
