# 경매사건 분석 스킬 v1.3

## 개요

대한민국 부동산 경매 사건의 권리분석·배당 시뮬레이션·투자 판단을
자동화하는 절차를 정의합니다.

## 입력 서류 및 역할

| 서류 | 역할 | 필수 여부 |
|------|------|---------|
| 등기사항전부증명서 (건물) | 말소기준권리 특정, 권리 시간표 | 필수 |
| 등기사항전부증명서 (토지) | 공동담보 확인, 공유지분 파악 | 필수 |
| 매각물건명세서 | 법원 공식 임차인 현황, 인수 권리 | 필수 |
| 현황조사서 | 실제 점유자, 보증금 실태 | 필수 |
| 감정평가서 | 물건 가치, 입지 정보, 토지 단가 | 필수 |
| 건축물대장 | 공부 불일치 확인 | 선택 |
| 기일내역 / 사건내역 | 유찰 횟수, 매각 일정 | 선택 |

## 분석 절차 (6단계 — 순서 변경 금지)

### STEP 1. 물건 기본정보 확인

다음 항목을 서류에서 추출하여 표로 정리:

```
- 사건번호 (예: 수원지방법원 2024타경85252)
- 법원 및 담당 계
- 채무자 / 소유자 (동일인 여부 명시. 법인인 경우 법인명 + 대표자 확인)
- 소재지 (지번 + 도로명)
- 물건 유형: 단독건물 / 집합건물(구분소유) / 토지 / 지분 중 명시
- 용도 (주거/근생/업무/공장 등. 공부상 용도 vs 실제 용도 불일치 시 표기)
- 구조 및 면적
- 감정평가액
- 현 최저매각가격
- 매각 회차 및 유찰 횟수
- 다음 매각기일
- 청구금액 (경매신청채권자 기준)
- 배당요구종기
```

---

### STEP 2. 말소기준권리 특정

**가장 중요한 단계. 이 판단이 틀리면 이후 모든 분석이 무효가 됨.**

#### 2-1. 등기부 권리 시간표 작성

건물·토지 등기부의 모든 권리를 접수일 기준 시간순으로 나열.
공동담보인 경우 하나의 채권으로 처리 (이중 계산 금지).

#### 2-2. 말소기준권리 식별

다음 중 가장 먼저 등기된 것이 말소기준권리:
- (근)저당권
- 압류 / 가압류 (단, 가압류만 있는 경우 첫 번째 가압류)
- 담보가등기
- 경매개시결정

⚠️ 주의사항:
- 가압류는 단독으로 말소기준권리가 될 수 없음
  (근저당 등이 없을 때만 최선순위 가압류가 기준권리)
- 채권최고액 ≠ 실채권액 (실채권 = 원금 + 이자, 채권최고액은 상한선)
  → 반드시 "채권최고액 X원 / 청구액 Y원 (채권최고액의 Z%)" 형식으로 병기
- 건물/토지에 동일 근저당이 걸린 경우 공동저당 → 채권은 1개
- 채권 승계(NPL 양도) 이력 확인: 원채권자 → 현 채권자 경로 추적
  → 근저당권이전 등기가 있으면 NPL 투자사 여부 확인

#### 2-3. 소멸·인수 권리 분류

| 구분 | 기준 | 낙찰 후 |
|------|------|---------|
| 말소기준권리 이전 등기 | 접수일 < 말소기준권리 접수일 | 낙찰자 인수 |
| 말소기준권리 이후 등기 | 접수일 > 말소기준권리 접수일 | 낙찰로 소멸 |
| 말소기준권리 자체 | - | 낙찰로 소멸 |

---

### STEP 3. 임차인 현황 및 대항력 판단

각 임차인에 대해 다음 체크리스트를 적용:

#### 3-1. 기본 정보 추출
```
- 성명
- 점유 부분 (주거/상가/혼재)
- 전입신고일 (주택) 또는 사업자등록일 (상가)
- 확정일자 및 일자
- 보증금액
- 배당요구 여부 및 일자
```

#### 3-2. 대항력 판단
```
전입일/사업자등록일 < 말소기준권리 접수일 → 대항력 O (낙찰자 인수 위험)
전입일/사업자등록일 ≥ 말소기준권리 접수일 → 대항력 X (낙찰로 소멸)
```

#### 3-3. 우선변제권 판단
```
대항력 + 확정일자 모두 갖춘 경우 → 배당 순위 획득
배당요구를 했는지 확인 (안 한 경우 배당 불가, 대항력만 존재)
```

#### 3-4. 소액임차인 최우선변제 해당 여부

지역별 소액임차인 기준 (2023년 이후 기준):
```
서울:               보증금 1억 6,500만원 이하 → 최우선변제 5,500만원
과밀억제권역(경기 등): 보증금 1억 4,500만원 이하 → 최우선변제 4,800만원
광역시:             보증금 8,500만원 이하 → 최우선변제 2,800만원
그 외:              보증금 7,500만원 이하 → 최우선변제 2,500만원
```

⚠️ **기준일 적용 원칙:** 소액임차인 판단 및 최우선변제액은 **말소기준권리 설정일 당시 시행 중인 기준**을 적용한다. 현재 기준 소급 적용 금지.

⚠️ **합산 한도:** 소액 최우선변제 합산액이 낙찰가의 1/2을 초과할 수 없음 (주임법 8조 4항). 임차인 10명 이상 물건은 반드시 합산 한도 계산.

#### 3-5. 위장임차인 의심 징후 체크

다음 중 2개 이상 해당 시 "위장임차인 의심" 판정:
```
□ 소유자·채무자와 동일 성씨 또는 친족으로 추정
□ 전입일이 말소기준권리 설정 3~12개월 이내
□ 보증금 미기재 또는 불명
□ 확정일자 없음
□ 배당요구를 하지 않음
□ 현장 조사 시 폐문 부재 / 점유 실태 불명
□ 실제 거주 흔적 없음 (감정평가서 기재)
```

### STEP 4. 특수 리스크 체크

각 항목을 반드시 검토. 해당 없으면 "해당없음"으로 명시.

#### [법정지상권]
```
1. 토지와 건물이 원래 동일인 소유였는가?
2. 근저당 설정 당시 토지·건물 소유자가 동일했는가?
3. 경매로 토지·건물 소유자가 달라지는가?
→ 3가지 모두 해당 → 법정지상권 성립 가능성 높음
- 미등기 건물(제시외 건물)이 토지 위에 있는가?
판정: 성립 가능 / 성립 불가 / 불분명
```

#### [유치권]
```
- 현황조사서에 유치권 신고 여부
- 공사 관련 채권자가 점유 중인지
- 물건명세서 비고란에 유치권 언급 여부
```

#### [공유지분 경매]
```
- 경매 대상이 전체인가, 지분인가
- 비경매 공유자 인적사항 및 지분 비율
- 공유자 우선매수청구권 행사 가능성
- 낙찰 후 공유물분할 소송 필요성
```

#### [체납 공과금]
```
- 등기부 압류 기관 목록 (국세청, 지자체, 공단 등)
- 법정기일이 근저당보다 앞선 조세채권 존재 가능성
  → 해당 시 근저당보다 선순위 배당 → 낙찰가에서 먼저 공제
- 사건내역의 교부청구서 제출 기관 확인
```

#### [공부 불일치 / 위반건축물]
```
- 등기부 vs 건축물대장 용도 차이
- 위반건축물 여부 → 해당 시 아래 4가지 추가 확인:

① 이행강제금 미납 잔액 (해당 구청 건축과 조회)
   - 연 2회 반복 부과, 횟수 제한 없음 → 방치 시 누적 급증
② 원상복구 명령 현황
   - 불법 증축: 철거 비용 ㎡당 50~150만원
   - 불법 용도변경: 원상복구 or 용도변경 허가 신청
③ 양성화(합법화) 가능 여부
   - 용도지역 허용 용도 + 건폐율·용적률 범위 내 → 양성화 가능
   - 양성화 비용: 건축사 용역 300~500만 + 허가수수료 50~100만
④ 감정평가서 위반건축물 감안 여부
   - 미감안 시 실제 가치 < 감정가

판정: 양성화 가능 / 양성화 불가(원상복구 필수) / 확인 필요
```

#### [신탁 이력]
```
등기부에 신탁/신탁해지 이력 있는 경우:
- 신탁원부 열람 권고
- 우선수익자 존재 여부 → 낙찰자 인수 가능성
판정: 신탁 잔여권리 없음 확인 / 신탁원부 확인 필요
```

#### [집합건물 특수사항]
```
아파트·오피스텔·상가 등 집합건물인 경우:
- 관리비 체납 승계 범위 (공용부분만 승계, 전유부분 미승계)
- 대지권 비율 및 대지권 등기 여부
- 층별·호별 위치에 따른 효용 차이
```

#### [반복 유찰 원인 분석]
3회 이상 유찰 시 반드시 분석:
```
□ 군용비행장 소음구역 / 비행안전구역
□ 관광특구 / 문화재보호구역
□ 초소형 면적 (10평 미만)
□ 위반건축물 등재
□ 채무자 법인 소멸 / 폐업
□ 임차인 다수 → 명도 복잡성
→ 구조적 원인이면 낙찰 후에도 동일 문제 지속됨을 명시
```

### STEP 4-A. 입지 분석

권리분석과 별도로, 임대 수요·임대료·자산 가치 상승 가능성을 결정하는 입지 요소를 점검. 수익형 임대 물건에서 특히 중요.

#### 4-A-1. 생활 인프라 체크리스트

있으면 ✓, 없으면 ✗, 거리 병기:
```
□ 자연환경: 공원·수변 도보 10분 이내
□ 대형마트·복합쇼핑: 도보 15분(1.2km) 이내
□ 학교: 초등학교 도보 10분 이내 (가족 세입자 수요)
□ 의료: 내과·소아과 밀집 1km 이내
□ 광역 교통: 서울 방향 광역버스 도보 5분 이내 (지하철 없는 지역 핵심)
□ 편의점·근린상가: 도보 3분 이내
```

점수화:
```
5개 이상 충족 → 생활 인프라 우수 (8점↑/10점)
3~4개 충족   → 보통 (5~7점)
2개 이하     → 취약 (4점↓) → 임대 수요 리스크 명시
```

#### 4-A-2. 교통 호재 진위 검증

"○○선 개통 예정" 언급 시 공식 출처로 반드시 확인:
```
① 공식 개통 목표 연도
   - 확인: 국토교통부 실시계획 고시 (고시번호 명시)
   - 지자체·언론 보도는 희망 일정인 경우 多 → 그대로 신뢰 금지

② 현재 공정률
   - 확인: 국가철도공단 발표 기준
   - 30% 미만 → 추가 지연 가능성 높음
   - 70% 이상 → 개통 가시화, 시장 선반영 시작

③ 급행 정차 여부
   - 완행만 정차 시 통근 실용성 크게 떨어짐
   - 급행 미정차 역 → 역세권 프리미엄 절반 이하로 계산
   - 확정 전까지 "급행 미정차 가정" 보수적 분석 필수

④ 역 위치 확정 여부
   - 가칭 역명 단계 vs. 실시계획 고시 단계 구분
   - 위치 미확정 시 역세권 편입 여부 자체가 불확실
```

#### 4-A-3. 역세권 거리 등급 기준

| 등급 | 거리 | 임대 영향 | 자산 가치 영향 |
|------|------|---------|-------------|
| 직접 역세권 | 500m 이내 (도보 7분) | 프리미엄 최대 | 개통 시 10~25% 상승 |
| 준역세권 | 500~1,000m (도보 13분) | 교통 편의 체감 | 개통 시 5~15% 상승 |
| 영향권 | 1,000~1,500m | 버스 환승 필요 | 개통 시 0~8% 상승 |
| 비역세권 | 1,500m 초과 | 실질 영향 미미 | 호재 디스카운트 미해소 |

※ 준역세권은 직접 역세권 프리미엄의 절반 수준으로 보수적 계산.

#### 4-A-4. 입지 종합 판정
```
🟢 입지 우수: 인프라 5개↑ + 현재 지하철 or 직접 역세권
🟡 입지 보통: 인프라 3~4개 + 준역세권 or 광역버스 대체
🔴 입지 취약: 인프라 2개↓ + 지하철 없고 호재 불확실
             → 공실 발생 시 수익성 급락 리스크 명시
```

### STEP 5. 배당 시뮬레이션

유찰 횟수에 따라 시나리오 기준 다르게 적용:

**일반 물건 (0~2회 유찰):**
- A: 현 최저매각가격 / B: 감정가의 70% / C: 감정가의 90%

**반복 유찰 물건 (3회 이상):**
- A: 현 최저매각가격 / B: 현 최저가 +20% / C: 청구채권액

#### 배당 순서 (법정 순서 — 변경 불가)
```
1순위: 경매 집행비용
2순위: 법정기일 선순위 조세채권 (국세, 지방세)
3순위: 소액임차인 최우선변제
4순위: 당해세
5순위: 우선변제권 있는 임차인 (확정일자 기준 순서)
6순위: (근)저당권자, 압류권자 (등기 순서)
7순위: 일반 채권자 (가압류 등)
```

#### 출력 형식
```
| 순위 | 권리자 | 청구금액 | A시나리오 | B시나리오 | C시나리오 |
|------|--------|---------|---------|---------|---------|
```

---

### STEP 6. 종합 판단

#### 리스크 등급 판정
```
🟢 안전: 말소기준권리 명확 + 인수 권리 없음 + 대항력 임차인 없음
         + 법정지상권 불가 + 체납 공과금 선순위 없음 + 신탁 잔여권리 없음

🟡 주의: 임차인 보증금 확인 필요 / 법정지상권 불분명 / 공유지분 리스크
         / 체납 공과금 규모 불명 / 반복 유찰 구조적 원인 / 신탁 원부 미확인

🔴 위험: 대항력 임차인 보증금 인수 확실 / 법정지상권 성립 가능
         / 유치권 신고 존재 / 선순위 조세채권 규모 큼 / 신탁 우선수익자 잔존
```

#### NPL 채권자 관점 (채권자가 NPL 투자사인 경우)
```
- 원채권자 → 현 채권자 양도 경로 추적
- 채권자 추정 매입가 (청구액의 60~80%)
- 채권자 손익분기점 낙찰가 역산
- 채권자 직접입찰 가능성
```

#### 다가구주택 다수 임차인 명도 비용 추산 (5세대 이상)
```
소요기간:
- 협의 명도: 세대당 1~2개월 → 10세대 기준 3~6개월
- 강제 명도: 세대당 6~12개월 → 10세대 기준 12~18개월

예상 비용:
- 이사비 지원(협의): 세대당 100~300만원
- 명도소송+강제집행: 세대당 80~170만원
- 고액 임차인(1억↑) + 배당 미달 → 소송 비용 반드시 반영
```

#### 입찰 전 필수 확인사항 (최대 5개)
현장·법원·행정 확인이 필요한 구체적 항목을 번호 목록으로 기술.

#### 투자자 최종 의견
적정 입찰가 범위와 한 줄 투자 판단.

## 분석 불가 항목 처리 규칙

```
- 서류에 없는 정보 → "서류 미확인 — 현장확인 필요"
- 법적 판단이 필요한 항목 → "전문가(변호사/법무사) 상담 권고"
- 숫자 불명확 시 → 범위로 표시 (예: 1,500만~3,000만원 추정)
- 추정으로 기술 금지
```

## 흔한 오류 방지

| 오류 유형 | 잘못된 판단 | 올바른 판단 |
|---------|-----------|-----------|
| 공동담보 이중 계산 | 건물+토지 각각 3.6억 = 7.2억 | 공동저당 채권 1개 = 3.6억 |
| 가압류를 말소기준권리로 오인 | 가압류가 기준권리 | 근저당이 진짜 기준권리 |
| 채권최고액을 실채권으로 혼동 | 3.6억 전액 배당 | 청구액(원금+이자)이 실채권 |
| 대항력 판단 기준일 착오 | 전입일 vs 근저당 설정일 | 전입일+거주 vs 근저당 접수일 |
| 소액임차인 기준 지역 착오 | 전국 동일 기준 | 수도권/광역시/기타 구분 |
| 소액임차인 기준 현재 소급 적용 | 현행 기준을 과거 근저당에 적용 | 근저당 설정일 당시 시행령 기준 |
| 소액 합산 한도 무시 | 10세대×2,700만=2.7억 전액 | 낙찰가 1/2 한도 초과분 배당 불가 |
| 집합건물 관리비 전액 승계 | 체납 전액 낙찰자 부담 | 공용부분만 승계 |
| 신탁 이력 무시 | 신탁해지 = 리스크 없음 | 신탁원부 확인 전까지 우선수익자 잔존 가능 |
| 반복유찰을 가격 문제로만 해석 | 더 내려가면 팔린다 | 구조적 원인 파악 선행 |
| 위반건축물 비용 무시 | 감정가 그대로 입찰가 기준 | 이행강제금·양성화 비용 차감 |
| 다가구 명도 비용 미반영 | 낙찰가만으로 수익성 판단 | 세대수×이사비·소송비 추산 후 실투자비 계산 |
| 교통 호재 과대평가 | 언론 보도 개통 연도 신뢰 | 국토부 실시계획 고시 기준 확인 |
| 역세권 거리 무기준 판단 | "역 근처라 좋다" 주관적 서술 | 500m/1,000m/1,500m 등급 기준 |
| 급행 정차 여부 미확인 | 역 개통 = 강남 30분 | 완행 정차역은 프리미엄 절반 이하 |
| 생활 인프라 미체크 | 권리분석만으로 투자 판단 | 공원·마트·학교·광역버스 체크리스트 |
