# 경매사건 분석 스킬

## 개요

이 스킬은 대한민국 부동산 경매 사건의 권리분석·배당 시뮬레이션·투자 판단을
자동화하는 절차를 정의합니다. Claude Code, Claude API, claude.ai 어디서든 동일하게
작동합니다.

## ⚠️ 적용 범위 및 향후 계획

### 현재 적용 범위 — 주거용 전용
```
✅ 적용 가능:
  - 단독주택 / 다가구주택
  - 아파트 / 연립 / 다세대 (집합건물)
  - 오피스텔 (주거용으로 사용 시)
  - 위 건물의 부속 토지

❌ 이 스킬 적용 불가 (별도 스킬 필요):
  - 상가 / 근린생활시설 (순수 상업용)
  - 오피스 / 업무시설
  - 공장 / 창고
  - 숙박시설 / 호텔
  - 상가주택 중 상가 비중이 큰 경우
```

### 📌 상업용 스킬 개발 예정 (SKILL-commercial.md)
```
주거용과 달라지는 핵심 항목:
- 법률 체계: 상가건물임대차보호법 적용
- 대항력 요건: 전입신고 → 사업자등록
- 소액임차인: 해당 없음 → 환산보증금(보증금 + 월세×100) 기준
- 수익 계산: 세대수 기준 → 업종·위치·층수·전용률·권리금
- 명도: 영업권·권리금 손실이 핵심 변수
- 임대 수익률: 수익환원법(Cap Rate) 적용

→ 상업용 경매 분석 시 이 파일 대신 SKILL-commercial.md 사용
→ 개발 시작 전 상업용 경매 사례 분석으로 항목 검증 필요
```

## 입력 서류 및 역할

### 파일명 접두사 매핑 (자동 분류 기준)

파일명 앞 2글자 접두사로 서류 종류를 즉시 판별한다.
파일 내용을 열기 전에 파일명으로 먼저 매핑하고, 내용으로 재확인.

| 접두사 | 서류 종류 | 역할 | 필수 여부 |
|--------|---------|------|---------|
| `AF`   | 감정평가서 | 물건 가치, 입지 정보, 토지 단가, 위반건축물 감안 여부 | 필수 |
| `AG`   | 매각물건명세서 | 법원 공식 임차인 현황, 인수 권리, 말소기준권리 | 필수 |
| `DA`   | 등기사항전부증명서 (토지) | 공동담보 확인, 공유지분 파악, 토지 권리 시간표 | 필수 |
| `DB`   | 등기사항전부증명서 (건물) | 말소기준권리 특정, 건물 권리 시간표 | 필수 |
| `EA`   | 전입세대확인서 (세대열람) | 실제 전입 세대 현황, 위장임차인 교차 확인 | 선택 |
| `EC`   | 건축물대장 | 공부 불일치, 위반건축물 여부, 층별 용도 확인 | 선택 |
| 접두사 없음 | 기일내역·사건내역·현황조사서 등 | 파일 내용으로 서류 종류 판별 | 선택 |

※ 접두사가 없거나 위 목록에 없는 경우 파일을 열어 내용으로 판별.
※ 동일 접두사 파일이 여러 개인 경우 파일명 뒷부분 번호(-0001, -1 등)로 구분.

### STEP 0A. 공통 투자 필터 (2단계 — 통과 못 하면 분석 중단)

#### 0A-1. 안전 마진 필터
```
감정가 대비 현 최저매각가격 비율 계산:
  현 최저가 ÷ 감정가 × 100 = 낙찰가율

판정:
  49% 이하 → ✅ 통과 (충분한 안전 마진 확보)
  50~64%   → ⚠️ 조건부 통과 (특수 리스크 해소 전제)
  65% 초과 → ❌ 분석 중단 — "일반 경쟁 물건, 특수경매 투자 대상 아님"
```

> 💡 핵심 원칙: 경매는 좋은 부동산이 아닌 '돈이 되는' 부동산을 사는 것.
> 감정적으로 지르지 말 것. 버스를 놓치면 리무진이 온다.

#### 0A-2. 출구 전략 필터
입찰 전 아래 3가지 질문에 모두 답이 나와야 진행:
```
① 누구에게 팔 것인가? (타 지분권자 / 건물주 / 일반 시장 등)
② 어떤 법적 논리로 압박할 것인가? (소송 종류 명시)
③ 얼마에 팔 수 있는가? (목표 매각가 범위)

→ 3가지 모두 답 가능 → ✅ 통과
→ 하나라도 불명확  → ❌ 분석 중단 — "출구 전략 미수립"
```

> 💡 낙찰은 투자의 50%. 나머지 50%는 권리를 풀고 나오는 것.

### STEP 0B. 물건 유형 분류 및 유형별 핵심 체크

#### 0B-1. 물건 유형 자동 분류
등기부·감정평가서 기준으로 아래 유형 중 하나로 분류:

| 유형 코드 | 유형명 | 분류 기준 |
|---------|------|---------|
| TYPE-A | 법정지상권 (건물 제외 토지) | 매각물건에 건물 제외 명시, 토지만 매각 |
| TYPE-B | 지분 경매 | 지분 경매, 공유물 분할 대상 |
| TYPE-C | 공장·창고 | 용도: 공장/창고/제조업, 기계 기구 포함 감정 |
| TYPE-D | 농지연금용 토지 | 지목: 전·답·과수원, 농지취득자격증명 필요 |
| TYPE-E | 아파트·다세대 | 집합건물 구분소유권 |
| TYPE-F | 기타·복합 | 위 유형에 해당하지 않거나 복합 물건 |

#### 0B-2. 유형별 핵심 체크 (유형 확정 후 즉시 실행)

**[TYPE-A] 법정지상권 물건 — 핵심 체크**
```
✅ 필수 확인:
□ 건물주(상대방)의 경제적 능력 추정 가능 여부
  → 건물 가치, 사업 영위 여부, 등기부상 채무 규모로 추정
□ 건물주의 현재 점유·거주 여부 (협상 동기 존재 여부)
□ 철거 소송 시 예상 소요 기간 및 비용 (통상 6~18개월)
□ 지료 청구 시 예상 월 지료 (인근 임대료 기준)

⛔ 즉시 탈락 조건:
- 건물주가 극빈층·요양병원 입원·행방불명으로 협상 불가
- 건물이 이미 철거되어 지료 청구 실익 없음
```

**[TYPE-B] 지분 경매 — 핵심 체크**
```
✅ 필수 확인:
□ 타 지분권자의 실거주 여부 (가족 거주 중이면 협상 동기↑)
□ 타 지분권자의 경제적 능력 (내 지분 매입 여력)
□ 공유자 우선매수청구권 행사 가능성
□ 공유물 분할 소송 시 현물분할 vs 경매 분할 가능성

⛔ 즉시 탈락 조건:
- 타 지분권자가 무자력·요양병원·사망으로 협상 불가
- 물건이 분할 불가능하고 경매 분할 시 저가 낙찰 우려
```

**[TYPE-C] 공장·창고 — 핵심 체크**
```
✅ 필수 확인:
□ 기반시설 완비 여부: 도로 접면, 전기(동력), 상하수도, 인허가
□ 감정가 중 기계 기구 비율 계산
  → 기계 제외 순수 토지+건물 가치 = 감정가 - 기계 기구 감정액
□ 배후 수요: 산업단지·물류 허브 인접 여부
□ 법인 명의 낙찰 가능 여부 (임대 운용 및 주식 양도 절세 플랜)

⛔ 즉시 탈락 조건:
- 기반시설(도로·전기) 미비로 실사용 불가
- 기계 기구 제외 시 실질 가치가 최저가 하회
```

**[TYPE-D] 농지연금용 토지 — 핵심 체크**
```
✅ 필수 확인:
□ 농기계 진입 가능한 최소 농로 존재 여부 (현황도로 포함)
□ 농취증 발급 가능 여부 (불법 임대·전용 이력 확인)
□ 연금 산정 기준: 공시지가(100%) vs 감정평가액(90%) 중 유리한 것
□ 낙찰가 대비 연금 월 수령액 손익분기점 계산
□ 2년 직접 영농 요건 충족 방법 (위탁 영농 가능 여부)

⛔ 즉시 탈락 조건:
- 농기계 진입 자체 불가능한 완전 맹지
- 이미 개발 완료·공장 전용되어 농지연금 신청 불가
- 타인 불법 임대 이력으로 농취증 반려 가능성 높음
```

**[TYPE-E] 아파트·다세대 — 핵심 체크**
```
✅ 필수 확인:
□ 위장임차인(가짜 대항력) 파악 가능 여부
  → 제1금융권 고액 대출 실행 이력 역추적
  → 전입일이 근저당 설정 직후인 경우 의심
□ 2~3년 임대 보유 후 시세 회복 가능성 (지역 수급 분석)
□ 명도 비용 및 기간 추정

⛔ 즉시 탈락 조건:
- 위장임차인 여부 불명확하고 대항력 있는 임차인 보증금이 큼
- 수요가 극히 한정된 전원주택지·오지
```

#### 0B-3. 공통 기피 물건 (유형 무관 — 해당 시 즉시 탈락)
```
⛔ 전원주택지: 34% 이하 폭락해도 재매각 엑시트 극히 어려움
⛔ 완전 맹지: 현황도로조차 없어 인허가 우회 불가한 토지
⛔ 협상 상대방 무자력: 소송 이겨도 지료·지분 매입 불가
⛔ 기계 허수 과대: 기계 제외 시 실질 가치가 최저가 하회
```

### STEP 1. 물건 기본정보 확인

다음 항목을 서류에서 추출하여 표로 정리:

```
- 사건번호 (예: 인천지방법원 부천지원 2024타경1298)
- 법원 및 담당 계
- 채무자 / 소유자 (동일인 여부 명시. 법인인 경우 법인명 + 대표자 확인)
- 소재지 (지번 + 도로명)
- 물건 유형: 단독건물 / 집합건물(구분소유) / 토지 / 지분 중 명시
- 용도 (주거/근생/업무/공장 등. 공부상 용도 vs 실제 용도 불일치 시 표기)
- 구조 및 면적
- 감정평가액
- 현 최저매각가격
- 매각 회차 및 유찰 횟수
- 다음 매각기일
- 청구금액 (경매신청채권자 기준)
- 배당요구종기
```

### STEP 2. 말소기준권리 특정

**가장 중요한 단계. 이 판단이 틀리면 이후 모든 분석이 무효가 됨.**

#### 2-1. 등기부 권리 시간표 작성

건물·토지 등기부의 모든 권리를 접수일 기준 시간순으로 나열.
공동담보인 경우 하나의 채권으로 처리 (이중 계산 금지).

#### 2-2. 말소기준권리 식별

다음 중 가장 먼저 등기된 것이 말소기준권리:
- (근)저당권
- 압류 / 가압류 (단, 가압류만 있는 경우 첫 번째 가압류)
- 담보가등기
- 경매개시결정

⚠️ 주의사항:
- 가압류는 단독으로 말소기준권리가 될 수 없음
  (근저당 등이 없을 때만 최선순위 가압류가 기준권리)
- 채권최고액 ≠ 실채권액 (실채권 = 원금 + 이자, 채권최고액은 상한선)
  → 반드시 "채권최고액 X원 / 청구액 Y원 (채권최고액의 Z%)" 형식으로 병기
- 건물/토지에 동일 근저당이 걸린 경우 공동저당 → 채권은 1개
- 채권 승계(NPL 양도) 이력 확인: 원채권자 → 현 채권자 경로 추적
  → 근저당권이전 등기가 있으면 NPL 투자사 여부 확인

#### 2-3. 소멸·인수 권리 분류

| 구분 | 기준 | 낙찰 후 |
|------|------|---------|
| 말소기준권리 이전 등기 | 접수일 < 말소기준권리 접수일 | 낙찰자 인수 |
| 말소기준권리 이후 등기 | 접수일 > 말소기준권리 접수일 | 낙찰로 소멸 |
| 말소기준권리 자체 | - | 낙찰로 소멸 |

---

### STEP 3. 임차인 현황 및 대항력 판단

각 임차인에 대해 다음 체크리스트를 적용:

#### 3-1. 기본 정보 추출
```
- 성명
- 점유 부분 (주거/상가/혼재)
- 전입신고일 (주택) 또는 사업자등록일 (상가)
- 확정일자 및 일자
- 보증금액
- 배당요구 여부 및 일자
```

#### 3-2. 대항력 판단
```
전입일/사업자등록일 < 말소기준권리 접수일 → 대항력 O (낙찰자 인수 위험)
전입일/사업자등록일 ≥ 말소기준권리 접수일 → 대항력 X (낙찰로 소멸)
```

#### 3-3. 우선변제권 판단
```
대항력 + 확정일자 모두 갖춘 경우 → 배당 순위 획득
배당요구를 했는지 확인 (안 한 경우 배당 불가, 대항력만 존재)
```

### STEP 4. 특수 리스크 체크

각 항목을 반드시 검토. 해당 없으면 "해당없음"으로 명시.

#### [법정지상권]

성립 요건 체크리스트:
```
1. 토지와 건물이 원래 동일인 소유였는가?
2. 근저당 설정 당시 토지·건물 소유자가 동일했는가?
3. 경매로 토지·건물 소유자가 달라지는가?
→ 3가지 모두 해당 → 법정지상권 성립 가능성 높음
```

추가 확인:
```
- 토지 공유인 경우: 공유자 중 한 명의 건물인가?
- 미등기 건물(제시외 건물)이 토지 위에 있는가?
- 감정평가서의 건물 소유 현황표 확인
```

판정: 성립 가능 / 성립 불가 / 불분명 (법원도 불분명으로 표기한 경우 그대로 따름)

#### [유치권]
```
- 현황조사서에 유치권 신고 여부
- 공사 관련 채권자가 점유 중인지
- 물건명세서 비고란에 유치권 언급 여부
```

#### [공유지분 경매]
```
- 경매 대상이 전체인가, 지분인가
- 비경매 공유자 인적사항 및 지분 비율
- 공유자 우선매수청구권 행사 가능성
- 낙찰 후 공유물분할 소송 필요성
- 구분소유적 공유 여부 (토지 위 건물을 각각 소유하는 경우)
```

#### [체납 공과금]
```
- 등기부 압류 기관 목록 (국세청, 지자체, 공단 등)

  → 해당 시 근저당보다 선순위 배당 → 낙찰가에서 먼저 공제
- 사건내역의 교부청구서 제출 기관 확인
```

#### [공부 불일치]
```
- 등기부 vs 건축물대장 용도 차이
- 공부상 구조 vs 현황 구조 차이 (예: 기와지붕 → 판넬지붕)
- 소재불명 건물 부속 (변소 등)
- 위반건축물 여부
```

### STEP 4-A. 입지 분석 ← NEW (2024타경85252 반영)

권리분석과 별도로, 임대 수요·임대료 수준·자산 가치 상승 가능성을 결정하는 입지 요소를 체계적으로 점검한다. 수익형 임대 물건(다가구·근린생활 혼재 등)에서 특히 중요.

#### 4-A-1. 생활 인프라 체크리스트

**웹 검색 수행 (서류에 없는 항목 보완):**
감정평가서·현황조사서만으로 파악이 안 되는 항목은 아래 쿼리로 웹 검색 후 보완.
```
검색 쿼리 예시:
- "[소재지 동명] 대형마트 편의시설"
- "[소재지 동명] 초등학교 학군"
- "[소재지] 버스 노선 광역버스"
- "[소재지 동명] 공원 산책"
```

임차 수요 예측을 위해 아래 항목을 반드시 확인. 있으면 ✓, 없으면 ✗, 거리 병기.

```
□ 자연환경: 공원·수변(호수·하천) 도보 10분 이내 여부
  → 있으면 거주 만족도·세입자 선호도 직결 (예: 만석공원 도보 3분)

□ 대형마트·복합쇼핑: 대형마트 또는 복합쇼핑몰 도보 15분(1.2km) 이내
  → 없으면 생활 불편 호소 → 세입자 이탈 리스크

□ 학교(초·중·고): 초등학교 도보 10분 이내 여부
  → 있으면 가족 세입자 수요 발생 → 장기 거주율 상승

□ 의료: 종합병원 또는 내과·소아과 밀집 여부 (1km 이내)

□ 광역 교통: 서울 방향 광역버스 정류장 도보 5분 이내
  → 지하철 없는 지역의 핵심 대체 요소

□ 편의점·근린상가: 도보 3분 이내 편의점 1개 이상
```

점수화 기준 (참고용):
```
항목 5개 이상 충족 → 생활 인프라 우수 (8점 이상/10점)
항목 3~4개 충족   → 보통 (5~7점)
항목 2개 이하     → 취약 (4점 이하) → 임대 수요 리스크 명시
```

#### 4-A-2. 교통 호재 진위 검증

**웹 검색 수행 (반드시 실행):**
서류에 언급이 없더라도 소재지 인근 교통 호재를 검색해 적극 반영.
```
검색 쿼리 예시:
- "[소재지 시·구] 전철 지하철 개통 예정 2026 2027 2028 2029"
- "[노선명] 개통일 공정률"
- "[노선명] [역명] 위치 도보거리"
```
검색 결과는 공식 출처(국토부·국가철도공단)와 언론 보도를 구분해 기재.
웹 검색으로도 정보가 불확실한 경우 "교통 호재 미확인 — 현장 확인 필요"로 기재.

"○○선 개통 예정"이 확인될 경우, 반드시 아래 4가지를 공식 출처로 재확인. 주민 기대감과 공식 일정이 크게 다른 경우가 많음.

```
① 공식 개통 목표 연도
   - 확인 출처: 국토교통부 실시계획 고시 (국토교통부고시 제○호)
   - 지자체·언론 보도는 희망 일정인 경우 多 → 鵜呑み 금지
   - 예: "2026년 개통 예정" 보도 → 공식 실시계획은 2029년 (2024타경85252 사례)

② 현재 공정률
   - 국가철도공단 또는 사업시행자 발표 기준
   - 공정률 30% 미만 → 추가 지연 가능성 높음
   - 공정률 70% 이상 → 개통 가시화 → 시장 선반영 시작

③ 급행 정차 여부
   - 완행만 정차 시 통근 실용성 크게 떨어짐
   - 급행 미정차 역은 역세권 프리미엄이 절반 이하
   - 확정 전까지 "급행 미정차 가정" 보수적 분석 필수

④ 역 위치 확정 여부
   - 가칭 역명 단계 vs. 실시계획 고시 단계 구분
   - 위치 미확정 시 역세권 편입 여부 자체가 불확실
```

### STEP 5. 배당 시뮬레이션

#### 시나리오 설정 규칙

**일반 물건 (0~2회 유찰):**
- A: 현 최저매각가격
- B: 감정가의 70%
- C: 감정가의 90%

**반복 유찰 물건 (3회 이상 유찰):**
- A: 현 최저매각가격
- B: 현 최저가 + 20% (소폭 경쟁 시나리오)
- C: 청구채권액 (채권자 손익분기점) — **단, 아래 조건 확인 후 적용**

```
C시나리오 적용 여부 판단:
  청구채권액 < 현 최저매각가격
  → C시나리오 실현 불가 → C시나리오 제외, A·B만 표시
  → 리포트에 "C시나리오: 청구채권액(XXX원)이 최저매각가격(XXX원) 미만으로 제외" 명시

  청구채권액 ≥ 현 최저매각가격
  → C시나리오 유효 → 정상 적용
```

#### 배당 계산 전 필수 사전 작업 (오류 방지)

배당표 작성 전 반드시 아래 순서로 확인:
```
① 말소기준권리 설정일 확인
   → STEP 3-4 기준표에서 해당 연도 소액 기준 선택

② 소액 해당 임차인 목록 확정
   → 각 임차인 보증금 vs 해당 지역·연도 한도 비교
   → 한도 초과 임차인은 소액 제외 (현행 기준 소급 적용 절대 금지)

③ 소액 최우선변제 합산액 계산
   → 합산액 ÷ A시나리오 낙찰가 → 1/2 초과 시 초과분 제외

④ 확정일자 기준 우선변제 순위 확정
   → 전입일 + 확정일자 중 늦은 날짜의 익일을 우선변제일로 사용
   → 우선변제일 오름차순 정렬

⑤ 공동담보 여부 확인
   → 건물·토지에 동일 채권의 근저당이 걸린 경우 채권 1개로만 계산
```

#### 배당 순서 (법정 순서 — 변경 불가)
```
1순위: 경매 집행비용
2순위: 법정기일 선순위 조세채권 (국세, 지방세 — 법정기일이 근저당보다 앞선 경우)
3순위: 소액임차인 최우선변제 (말소기준권리 설정일 당시 기준 적용)
4순위: 당해세 (해당 부동산에 부과된 재산세·종부세 등)
5순위: 우선변제권 있는 임차인 (우선변제일 오름차순)
6순위: (근)저당권자, 압류권자 (등기 접수일 순서)
7순위: 일반 채권자 (가압류 등)
```

```
| 순위 | 권리자 | 청구금액 | A배당 | B배당 | 비고 |

핵심 포인트:
```

#### NPL 채권자 관점 분석 ← NEW

현장·법원·행정 확인이 필요한 구체적인 항목을 번호 목록으로 기술.

#### 다가구주택 다수 임차인 명도 비용 추산 (5세대 이상)
```
예상 소요기간:
- 협의 명도 (임차인 협조 시): 세대당 1~2개월 → 10세대 기준 총 3~6개월
- 강제 명도 (소송 필요 시): 세대당 6~12개월 → 10세대 기준 총 12~18개월
- 대항력 없는 임차인도 명도소송+강제집행 시 수개월 소요됨

예상 비용:
- 이사비 지원 (협의 시): 세대당 100~300만원 (보증금 규모·이전거리 비례)
- 명도소송 비용: 세대당 소송비 50~100만원 + 강제집행비 30~70만원
- 10세대 전체 협의 명도 기준: 총 1,000~3,000만원 수준

판단 기준:
- 소액 임차인(보증금 3,000만 이하): 협의 가능성 높음
- 고액 임차인(1억 이상) + 배당 미달: 명도 저항 가능성 높음 → 소송 비용 반영
- 위장임차인 의심 세대: 실거주 없으면 공실로 명도 불필요
```

#### 수익 계산 및 출구 전략 (수익형 임대 물건 해당 시)

수익형 임대 물건(다가구·근린생활 혼재 등)인 경우 반드시 추가 수행.
순수 거주 목적 단독주택·아파트 1세대는 생략 가능.

**[1단계] 실투자금 산출**
```
실투자금 = 낙찰가
         + 취득세
         + 법무사·경매 비용
         + 명도비
         + 위반건축물 양성화·수리비 (해당 시)
         + 리모델링비 (준공년도·상태 기준)
         - 임차보증금 회수분 (전세 재임대 시)

취득세 기준:
- 1주택 (6억 이하): 1%
- 1주택 (6억~9억): 1~3% 구간세율
- 1주택 (9억 초과): 3%
- 2주택 조정대상지역: 8%
- 3주택 이상 또는 법인: 12%
- 다가구주택 (1주택으로 봄): 공시가 기준 적용
⚠️ 취득세율은 보유 주택 수·지역·법인 여부에 따라 크게 달라짐.
   분석 시 "투자자 보유 현황 미확인"으로 범위 제시.
```

**[2단계] 임대 수익 추산**
```
층별 현황 기반으로 세대별 시세 추산:
- 전세: 인근 유사 면적 전세 시세 참고 (감정평가서 거래사례 활용)
- 월세: 보증금 + 월세 구조 (전월세전환율 4~6% 기준)
- 상가(1층): 보증금 + 월 임대료

월 임대수익 합산 = Σ(세대별 월세 수입) + 상가 월세
연 임대수익 = 월 임대수익 × 12
```

**[3단계] 출구 전략 시나리오 3가지**
```
시나리오 A — 임대 운영
  연 수익률 = 연 임대수익 ÷ 실투자금 × 100
  월 현금흐름 = 월 임대수익 - 대출이자(있는 경우) - 관리비
  판단 기준: 연 수익률 5% 이상 → 양호 / 3~5% → 보통 / 3% 미만 → 재검토

시나리오 B — 단기 매각 (명도 완료 후)
  예상 매각가 = 토지 감정단가 × 면적 × 시세 보정
              또는 인근 유사 거래사례 기준
  보유기간별 수익: (매각가 - 실투자금 - 양도세 추정) ÷ 보유월수
  판단 기준: 연환산 수익률 10% 이상 → 적극 검토

시나리오 C — 혼합 전략 (일부 전세 + 일부 월세 + N년 후 매각)
  전세 세대: 보증금으로 실투자금 회수 → 현금 부담 최소화
  월세 세대: 월 현금흐름 확보
  N년 후 매각: 교통 호재(역 개통 등) 시점에 맞춰 매각 타이밍 설정
  최적 조합: 실투자금 회수 가능한 전세 세대수 + 수익률 극대화 월세 배분

→ 세 시나리오 중 물건 특성에 맞는 최적안 1개를 추천하고 이유 명시
```

**[4단계] 손익분기 낙찰가 역산**
```
목표 수익률(연 5% 또는 투자자 기준) 달성을 위한 최대 낙찰가:
  최대 낙찰가 = (연 임대수익 ÷ 목표수익률) - 부대비용
  또는
  최대 낙찰가 = 예상 매각가 × (1 - 목표 수익마진) - 부대비용

→ 이 금액을 초과한 입찰은 수익성 미달 → 입찰 포기 기준선으로 활용
```

|---------|-----------|-----------|
| 공동담보 이중 계산 | 건물+토지 근저당 각각 3.6억 = 7.2억 | 공동저당 채권 1개 = 3.6억 한도 |
| 가압류를 말소기준권리로 오인 | 2023년 가압류가 기준권리 | 2021년 근저당이 진짜 기준권리 |
| 채권최고액을 실채권으로 혼동 | 3.6억 전액 배당 | 청구액(원금+이자)이 실채권 |
| 대항력 판단 기준일 착오 | 전입일 vs 근저당 설정일 비교 | 전입일+거주 vs 근저당 접수일 비교 |
| 소액임차인 기준 지역 착오 | 전국 동일 기준 적용 | 수도권/광역시/기타 구분 적용 |
| 집합건물 관리비 전액 승계 | 체납 관리비 전액 낙찰자 부담 | 공용부분 체납만 승계, 전유부분 미승계 |
| 신탁 이력 무시 | 신탁해지 = 리스크 없음 | 신탁원부 확인 전까지 우선수익자 잔존 가능 |
| 반복유찰을 가격 문제로만 해석 | 더 내려가면 팔린다 | 구조적 원인(소음·규제·면적) 파악 선행 필요 |

| 교통 호재 과대평가 | 지역 언론 "2026년 개통" 기사 그대로 신뢰 | 국토부 실시계획 고시 기준 공식 개통 연도·공정률 확인 |
| 역세권 거리 무기준 판단 | "역 근처라 좋다" 주관적 서술 | 500m/1,000m/1,500m 등급 기준으로 프리미엄 보수적 계산 |
| 급행 정차 여부 미확인 | 역 개통 = 강남 30분 광고 鵜呑み | 완행 정차 역은 급행 대비 프리미엄 절반 이하로 계산 |
| 생활 인프라 미체크 | 권리분석만 하고 임대 수요 미검토 | 공원·마트·학교·광역버스 체크리스트로 임차 수요 예측 |
| 위반건축물 비용 무시 | 감정가 그대로 입찰가 기준 삼음 | 이행강제금·원상복구·양성화 비용 추산 후 차감 |
| 소액임차인 기준 현재 기준 소급 적용 | 현행 기준(4,800만)을 2015년 근저당에 적용 | 근저당 설정일 당시 시행령 기준 금액 적용 |
| 다가구 명도 비용 미반영 | 낙찰가만으로 수익성 판단 | 세대수×이사비·소송비 추산 후 실투자비 계산 |
| 소액 최우선변제 합산 한도 무시 | 10세대 × 2,700만 = 2.7억 전액 인정 | 낙찰가의 1/2 한도 초과분은 배당 불가 |

## Claude Code 사용 예시

```python
# 사용 예: Claude Code에서 스킬 활용
# SKILL.md를 읽은 후 경매 서류 PDF를 분석

import anthropic
import base64

def analyze_auction(pdf_paths: dict) -> str:
    """
    pdf_paths = {
        "등기부_건물": "path/to/building_registry.pdf",
        "등기부_토지": "path/to/land_registry.pdf",
        "물건명세서": "path/to/property_spec.pdf",
        "현황조사서": "path/to/current_status.pdf",
        "감정평가서": "path/to/appraisal.pdf",
    }
    """
    client = anthropic.Anthropic()

    # PDF를 base64로 변환
    content = []
    for name, path in pdf_paths.items():
        with open(path, "rb") as f:
            data = base64.standard_b64encode(f.read()).decode()
        content.append({
            "type": "document",
            "source": {"type": "base64", "media_type": "application/pdf", "data": data},
            "title": name
        })

    content.append({
        "type": "text",
        "text": "위 경매 서류들을 분석해주세요."
    })

    response = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=8000,
        system=SYSTEM_PROMPT,  # 아래 참조
        messages=[{"role": "user", "content": content}]
    )

    return response.content[0].text


SYSTEM_PROMPT = """
당신은 대한민국 부동산 경매 전문 권리분석가입니다.
10년 이상의 특수경매 실무 경험을 가지며, NPL 투자·법정지상권·위장임차인·공유지분에 정통합니다.

반드시 아래 6단계를 순서대로 수행하십시오:

STEP 1: 물건 기본정보 (사건번호, 소재지, 감정가, 최저가, 유찰횟수)
STEP 2: 말소기준권리 특정 (모든 권리 시간순 나열 → 기준권리 식별 → 소멸/인수 분류)
STEP 3: 임차인 대항력 판단 (전입일 vs 말소기준권리일 비교, 위장임차인 징후 체크)
STEP 4: 특수 리스크 (법정지상권, 유치권, 공유지분, 체납공과금, 공부불일치)
STEP 5: 배당 시뮬레이션 (낙찰가 3개 시나리오, 권리자별 배당액 표)
STEP 6: 종합 판단 (리스크 등급 🟢🟡🔴, 적정 입찰가, 확인사항)

절대 금지:
- 서류에 없는 정보 추정 기술
- 공동담보 채권 이중 계산
- 가압류를 말소기준권리로 오인
- 채권최고액을 실채권으로 혼동
"""
```
