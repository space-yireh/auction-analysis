# 경매사건 분석 스킬

## 개요

이 스킬은 대한민국 부동산 경매 사건의 권리분석·배당 시뮬레이션·투자 판단을
자동화하는 절차를 정의합니다. Claude Code, Claude API, claude.ai 어디서든 동일하게
작동합니다.

## 입력 서류 및 역할

| 서류 | 역할 | 필수 여부 |
|------|------|---------|
| 등기사항전부증명서 (건물) | 말소기준권리 특정, 권리 시간표 | 필수 |
| 등기사항전부증명서 (토지) | 공동담보 확인, 공유지분 파악 | 필수 |
| 매각물건명세서 | 법원 공식 임차인 현황, 인수 권리 | 필수 |
| 현황조사서 | 실제 점유자, 보증금 실태 | 필수 |
| 감정평가서 | 물건 가치, 입지 정보, 토지 단가 | 필수 |
| 건축물대장 | 공부 불일치 확인 | 선택 |
| 기일내역 / 사건내역 | 유찰 횟수, 매각 일정 | 선택 |

---

## 분석 절차 (6단계 — 순서 변경 금지)

### STEP 1. 물건 기본정보 확인

다음 항목을 서류에서 추출하여 표로 정리:

```
- 사건번호 (예: 인천지방법원 부천지원 2024타경1298)
- 법원 및 담당 계
- 채무자 / 소유자 (동일인 여부 확인)
- 소재지 (지번 + 도로명)
- 용도 (주거/근생/공장 등)
- 구조 및 면적
- 감정평가액
- 현 최저매각가격
- 매각 회차 및 유찰 횟수
- 다음 매각기일
- 청구금액 (경매신청채권자 기준)
- 배당요구종기
```

---

### STEP 2. 말소기준권리 특정

**가장 중요한 단계. 이 판단이 틀리면 이후 모든 분석이 무효가 됨.**

#### 2-1. 등기부 권리 시간표 작성

건물·토지 등기부의 모든 권리를 접수일 기준 시간순으로 나열.
공동담보인 경우 하나의 채권으로 처리 (이중 계산 금지).

#### 2-2. 말소기준권리 식별

다음 중 가장 먼저 등기된 것이 말소기준권리:
- (근)저당권
- 압류 / 가압류 (단, 가압류만 있는 경우 첫 번째 가압류)
- 담보가등기
- 경매개시결정

⚠️ 주의사항:
- 가압류는 단독으로 말소기준권리가 될 수 없음
  (근저당 등이 없을 때만 최선순위 가압류가 기준권리)
- 채권최고액 ≠ 실채권액 (실채권 = 원금 + 이자, 채권최고액은 상한선)
- 건물/토지에 동일 근저당이 걸린 경우 공동저당 → 채권은 1개

#### 2-3. 소멸·인수 권리 분류

| 구분 | 기준 | 낙찰 후 |
|------|------|---------|
| 말소기준권리 이전 등기 | 접수일 < 말소기준권리 접수일 | 낙찰자 인수 |
| 말소기준권리 이후 등기 | 접수일 > 말소기준권리 접수일 | 낙찰로 소멸 |
| 말소기준권리 자체 | - | 낙찰로 소멸 |

---

### STEP 3. 임차인 현황 및 대항력 판단

각 임차인에 대해 다음 체크리스트를 적용:

#### 3-1. 기본 정보 추출
```
- 성명
- 점유 부분 (주거/상가/혼재)
- 전입신고일 (주택) 또는 사업자등록일 (상가)
- 확정일자 및 일자
- 보증금액
- 배당요구 여부 및 일자
```

#### 3-2. 대항력 판단
```
전입일/사업자등록일 < 말소기준권리 접수일 → 대항력 O (낙찰자 인수 위험)
전입일/사업자등록일 ≥ 말소기준권리 접수일 → 대항력 X (낙찰로 소멸)
```

#### 3-3. 우선변제권 판단
```
대항력 + 확정일자 모두 갖춘 경우 → 배당 순위 획득
배당요구를 했는지 확인 (안 한 경우 배당 불가, 대항력만 존재)
```

#### 3-4. 소액임차인 최우선변제 해당 여부
지역별 소액임차인 기준 (2023년 기준):
```
서울:     보증금 1억 6,500만원 이하 → 최우선변제 5,500만원
과밀억제권역(경기 등): 보증금 1억 4,500만원 이하 → 최우선변제 4,800만원
광역시:   보증금 8,500만원 이하 → 최우선변제 2,800만원
그 외:    보증금 7,500만원 이하 → 최우선변제 2,500만원
```

⚠️ 기준일에 따라 금액이 다름. 근저당 설정일 당시 기준 적용.

#### 3-5. 위장임차인 의심 징후 체크

다음 중 2개 이상 해당 시 "위장임차인 의심" 판정:
```
□ 소유자·채무자와 동일 성씨 또는 친족으로 추정
□ 전입일이 말소기준권리 설정 3~12개월 이내
□ 보증금 미기재 또는 불명
□ 확정일자 없음
□ 배당요구를 하지 않음
□ 현장 조사 시 폐문 부재 / 점유 실태 불명
□ 실제 거주 흔적 없음 (감정평가서 기재)
```

---

### STEP 4. 특수 리스크 체크

각 항목을 반드시 검토. 해당 없으면 "해당없음"으로 명시.

#### [법정지상권]

성립 요건 체크리스트:
```
1. 토지와 건물이 원래 동일인 소유였는가?
2. 근저당 설정 당시 토지·건물 소유자가 동일했는가?
3. 경매로 토지·건물 소유자가 달라지는가?
→ 3가지 모두 해당 → 법정지상권 성립 가능성 높음
```

추가 확인:
```
- 토지 공유인 경우: 공유자 중 한 명의 건물인가?
- 미등기 건물(제시외 건물)이 토지 위에 있는가?
- 감정평가서의 건물 소유 현황표 확인
```

판정: 성립 가능 / 성립 불가 / 불분명 (법원도 불분명으로 표기한 경우 그대로 따름)

#### [유치권]
```
- 현황조사서에 유치권 신고 여부
- 공사 관련 채권자가 점유 중인지
- 물건명세서 비고란에 유치권 언급 여부
```

#### [공유지분 경매]
```
- 경매 대상이 전체인가, 지분인가
- 비경매 공유자 인적사항 및 지분 비율
- 공유자 우선매수청구권 행사 가능성
- 낙찰 후 공유물분할 소송 필요성
- 구분소유적 공유 여부 (토지 위 건물을 각각 소유하는 경우)
```

#### [체납 공과금]
```
- 등기부 압류 기관 목록 (국세청, 지자체, 공단 등)
- 법정기일이 근저당보다 앞선 조세채권 존재 가능성
  → 해당 시 근저당보다 선순위 배당 → 낙찰가에서 먼저 공제
- 사건내역의 교부청구서 제출 기관 확인
```

#### [공부 불일치]
```
- 등기부 vs 건축물대장 용도 차이
- 공부상 구조 vs 현황 구조 차이 (예: 기와지붕 → 판넬지붕)
- 소재불명 건물 부속 (변소 등)
- 위반건축물 여부
```

---

### STEP 5. 배당 시뮬레이션

낙찰가 시나리오 3개에 대해 배당표 작성:
- A: 현 최저매각가격
- B: 감정가의 70%
- C: 감정가의 90%

#### 배당 순서 (법정 순서 — 변경 불가)
```
1순위: 경매 집행비용
2순위: 법정기일 선순위 조세채권 (국세, 지방세)
3순위: 소액임차인 최우선변제
4순위: 당해세 (해당 부동산에 부과된 세금)
5순위: 우선변제권 있는 임차인 (확정일자 기준 순서)
6순위: (근)저당권자, 압류권자 (등기 순서대로)
7순위: 일반 채권자 (가압류 등)
```

#### 출력 형식
```
| 순위 | 권리자 | 청구금액 | A시나리오 배당 | B시나리오 배당 | C시나리오 배당 |
|------|--------|---------|--------------|--------------|--------------|
| 1    | 집행비용 | (추정) | XX만원 | XX만원 | XX만원 |
...
| 최하 | 낙찰자 인수 | - | XX만원 | XX만원 | XX만원 |
```

### STEP 6. 종합 판단

#### 리스크 등급 판정
```
🟢 안전: 아래 조건 모두 충족
  - 말소기준권리 명확
  - 인수되는 권리 없음
  - 임차인 대항력 없음 또는 보증금 소액
  - 법정지상권 성립 불가
  - 체납 공과금 선순위 없음

🟡 주의: 다음 중 하나 해당
  - 임차인 보증금 확인 필요
  - 법정지상권 불분명
  - 공유지분 리스크 있음
  - 체납 공과금 규모 불명

🔴 위험: 다음 중 하나 해당
  - 대항력 있는 임차인의 보증금 인수 확실
  - 법정지상권 성립 가능성 높음
  - 유치권 신고 존재
  - 선순위 조세채권 규모 큼
```

#### 입찰 전 필수 확인사항 (최대 5개)
현장·법원·행정 확인이 필요한 구체적인 항목 기술.

#### 투자자 최종 의견
적정 입찰가 범위와 한 줄 투자 판단.

## 분석 불가 항목 처리 규칙

```
- 서류에 없는 정보 → "서류 미확인 — 현장확인 필요"
- 법적 판단이 필요한 항목 → "전문가(변호사/법무사) 상담 권고"
- 숫자가 불명확한 경우 → 범위로 표시 (예: 1,500만~3,000만원 추정)
- 절대 추정으로 기술하지 않음
```

## 흔한 오류 방지

| 오류 유형 | 잘못된 판단 | 올바른 판단 |
|---------|-----------|-----------|
| 공동담보 이중 계산 | 건물+토지 근저당 각각 3.6억 = 7.2억 | 공동저당 채권 1개 = 3.6억 한도 |
| 가압류를 말소기준권리로 오인 | 2023년 가압류가 기준권리 | 2021년 근저당이 진짜 기준권리 |
| 채권최고액을 실채권으로 혼동 | 3.6억 전액 배당 | 청구액(원금+이자)이 실채권 |
| 대항력 판단 기준일 착오 | 전입일 vs 근저당 설정일 비교 | 전입일+거주 vs 근저당 접수일 비교 |
| 소액임차인 기준 지역 착오 | 전국 동일 기준 적용 | 수도권/광역시/기타 구분 적용 |

## Claude Code 사용 예시

```python
# 사용 예: Claude Code에서 스킬 활용
# SKILL.md를 읽은 후 경매 서류 PDF를 분석

import anthropic
import base64

def analyze_auction(pdf_paths: dict) -> str:
    """
    pdf_paths = {
        "등기부_건물": "path/to/building_registry.pdf",
        "등기부_토지": "path/to/land_registry.pdf",
        "물건명세서": "path/to/property_spec.pdf",
        "현황조사서": "path/to/current_status.pdf",
        "감정평가서": "path/to/appraisal.pdf",
    }
    """
    client = anthropic.Anthropic()

    # PDF를 base64로 변환
    content = []
    for name, path in pdf_paths.items():
        with open(path, "rb") as f:
            data = base64.standard_b64encode(f.read()).decode()
        content.append({
            "type": "document",
            "source": {"type": "base64", "media_type": "application/pdf", "data": data},
            "title": name
        })

    content.append({
        "type": "text",
        "text": "위 경매 서류들을 분석해주세요."
    })

    response = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=8000,
        system=SYSTEM_PROMPT,  # 아래 참조
        messages=[{"role": "user", "content": content}]
    )

    return response.content[0].text


SYSTEM_PROMPT = """
당신은 대한민국 부동산 경매 전문 권리분석가입니다.
10년 이상의 특수경매 실무 경험을 가지며, NPL 투자·법정지상권·위장임차인·공유지분에 정통합니다.

반드시 아래 6단계를 순서대로 수행하십시오:

STEP 1: 물건 기본정보 (사건번호, 소재지, 감정가, 최저가, 유찰횟수)
STEP 2: 말소기준권리 특정 (모든 권리 시간순 나열 → 기준권리 식별 → 소멸/인수 분류)
STEP 3: 임차인 대항력 판단 (전입일 vs 말소기준권리일 비교, 위장임차인 징후 체크)
STEP 4: 특수 리스크 (법정지상권, 유치권, 공유지분, 체납공과금, 공부불일치)
STEP 5: 배당 시뮬레이션 (낙찰가 3개 시나리오, 권리자별 배당액 표)
STEP 6: 종합 판단 (리스크 등급 🟢🟡🔴, 적정 입찰가, 확인사항)

절대 금지:
- 서류에 없는 정보 추정 기술
- 공동담보 채권 이중 계산
- 가압류를 말소기준권리로 오인
- 채권최고액을 실채권으로 혼동
"""
```
